# 🌟 Content Portfolio

Welcome to my **Content Portfolio** repository!

This project is a multimedia portfolio website developed using core frontend technologies. It showcases different types of digital content including images, audio, and video in a structured and visually organized format.

The purpose of this project is to demonstrate content presentation, media integration, and fundamental web development skills using HTML, CSS, and JavaScript.

---

## 📖 About the Project

The Content Portfolio is a static web-based project designed to display and manage multimedia content on a single platform.

This project demonstrates:

- Integration of images within a web page
- Embedding and controlling audio files
- Embedding and playing video files
- Clean and simple user interface design
- Basic interactivity using JavaScript
- Organized project structure

It serves as a foundational portfolio-style website that can be extended into a more advanced personal or professional portfolio in the future.

## 🛠️ Technologies Used

The project is built using:

- HTML5 – For structuring the website
- CSS3 – For styling and layout design
- JavaScript – For adding interactivity and dynamic behavior

No external libraries or frameworks are used. The project focuses on core web development fundamentals.

---

## 📂 Project Structure

Content_portfolio/
│
├── index.html        → Main webpage file  
├── styles.css        → Styling file  
├── script.js         → JavaScript functionality  
├── package.json      → Project configuration (if included)  
│
├── image files       → .jpg / .png files  
├── audio files       → .mp3 files  
├── video files       → .mp4 files  
│
└── README.md         → Project documentation  

The structure may slightly vary depending on uploaded files.

## 🚀 How to Run the Project Locally

Follow these simple steps:

1. Clone the repository

   git clone https://github.com/shubha0503/Content_portfolio.git

2. Open the project folder

   cd Content_portfolio

3. Run the project

   Open the index.html file directly in your browser

OR

   Use Live Server in VS Code for better development experience

---

## 🌐 Hosting with GitHub Pages

You can deploy this project using GitHub Pages:

1. Go to your GitHub repository
2. Click on Settings
3. Select Pages
4. Choose branch: main
5. Click Save

After deployment, your site will be available at:

https://shubha0503.github.io/Content_portfolio/
